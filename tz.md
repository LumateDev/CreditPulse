# Техническое задание на разработку ИСППР

## 1. Утвержденная формулировка задачи, для которой создается модель

**Формулировка задачи:**  
Разработка интеллектуальной системы поддержки принятия решений (ИСППР) для оценки кредитоспособности заемщика на основе его социально-экономических характеристик и параметров кредита.

**Цель:**  
Создать систему, которая:

- прогнозирует риск дефолта заемщика (классификация: good/bad или 0/1)
- формирует рекомендацию по выдаче кредита
- предоставляет интерпретируемое текстовое объяснение принятого решения

## 2. Обоснование выбора входных данных для обучения модели

**Входные данные:**

*Характеристики заемщика:*

- возраст
- доход
- стаж работы
- тип занятости
- тип жилья

*Параметры кредита:*

- сумма кредита
- срок кредита
- процентная ставка
- цель кредита

*Кредитная история:*

- кредитная история
- наличие прошлых дефолтов
- кредитная нагрузка (доля платежа от дохода)

*Целевая переменная:*

- риск заемщика (good/bad или loan_status)

**Обоснование выбора:**

- **Релевантность к задаче:**  
  Признаки напрямую отражают финансовое состояние заемщика и используются в реальных кредитных скоринговых системах.

- **Доступность и разнообразие:**  
  Данные включают числовые и категориальные признаки, что позволяет учитывать различные аспекты риска.

- **Техническая эффективность:**  
  Данные имеют структурированный формат, что упрощает предобработку и обучение моделей без значительных вычислительных затрат.

- **Ограничения и альтернативы:**  
  Часть признаков исключена как избыточная или слабо влияющая. Возможным расширением является добавление дополнительных финансовых показателей при наличии данных.

## 3. Техническое задание на разработку опытного образца системы ИИ

### Общие положения

Разрабатываемая система представляет собой программный прототип ИСППР, предназначенный для:

- анализа данных заемщика
- прогнозирования кредитного риска
- формирования рекомендации по выдаче кредита
- генерации текстового объяснения решения с использованием языковой модели (LLM)

Система реализуется в виде модульного программного решения.

### Перечень требований к выполняемым работам

1. **Анализ и проектирование:**

   - анализ предметной области кредитного скоринга
   - исследование и подготовка датасетов
   - выбор признаков
   - проектирование архитектуры системы (модульный подход)

2. **Разработка ПО:**

   - реализация модуля предобработки данных
   - разработка нейросетевой модели
   - реализация модуля расчета влияния признаков
   - интеграция LLM для генерации объяснений

3. **Обучение и оптимизация модели:**

   - обучение нейронной сети
   - настройка гиперпараметров
   - оценка качества модели
   - сравнение с базовыми моделями (при необходимости)

4. **Тестирование и валидация:**

   - оценка точности (accuracy, precision, recall)
   - проверка устойчивости модели
   - тестирование корректности объяснений

5. **Документирование и поставка:**

   - описание архитектуры системы
   - инструкция по запуску
   - описание ограничений модели
   - подготовка демонстрационных примеров

### Функциональные требования

Система должна:

- принимать входные данные заемщика
- выполнять предсказание вероятности дефолта
- классифицировать заемщика (good/bad)
- формировать рекомендацию (одобрить/отказать)
- определять ключевые факторы, повлиявшие на решение
- генерировать текстовое объяснение с использованием LLM

### Выходные данные модели

- вероятность дефолта (от 0 до 1)
- класс заемщика (good/bad)
- рекомендация (одобрить / отказать)
- список факторов влияния (числовые оценки)
- текстовое объяснение решения

### Состав и структура компонентов изделия

Опытный образец состоит из следующих компонентов:

1. **Модуль предобработки данных:**

   - загрузка и очистка данных
   - кодирование категориальных признаков
   - нормализация числовых признаков

2. **ИИ-модель (ядро):**

   - нейронная сеть для классификации заемщиков
   - вычисление вероятности дефолта

3. **Модуль расчета влияния признаков:**

   - определение вклада признаков (например, на основе весов модели или упрощенной модели)
   - формирование списка значимых факторов

4. **Модуль инференса:**

   - получение предсказаний модели
   - применение порогового правила для принятия решения

5. **Модуль генерации объяснений (LLM):**

   - получение факторов влияния
   - формирование текстового объяснения решения

6. **Интерфейс и утилиты:**

   - ввод данных пользователя
   - отображение результатов
   - визуализация

7. **Документация и тесты:**

   - руководство пользователя
   - тестовые сценарии

### Пример работы системы

**📌 Входные данные заемщика:**

- возраст: 28 лет
- доход: 35 000
- стаж работы: 1 год
- тип жилья: аренда
- сумма кредита: 20 000
- срок: 36 месяцев
- процентная ставка: 15%
- кредитная история: были просрочки

**📊 Результат модели:**

- вероятность дефолта: 0.68
- класс: плохой заемщик
- рекомендация: ❌ отказать

**📈 Определенные факторы влияния:**

- высокая сумма кредита (+)
- низкий доход (+)
- небольшой стаж работы (+)
- наличие просрочек (+)

**🧠 Текстовое объяснение (LLM):**  
Высокий риск невозврата кредита обусловлен значительной суммой займа при относительно низком уровне дохода заемщика. Дополнительным фактором является небольшой стаж работы и наличие просрочек в кредитной истории, что снижает надежность клиента. В связи с этим рекомендуется отказать в выдаче кредита.

### Этапы разработки

1. **Анализ предметной области:**  
   Изучение методов кредитного скоринга и факторов, влияющих на риск заемщика.

2. **Проектирование модели:**  
   Определение архитектуры нейронной сети, входных и выходных параметров.

3. **Программная реализация:**  
   Разработка модулей системы, включая модель и LLM-интеграцию.

4. **Подготовка данных:**  
   Очистка, преобразование и формирование обучающей выборки.

5. **Обучение модели:**  
   Обучение нейронной сети и настройка параметров.

6. **Тестирование и отладка:**  
   Проверка корректности работы системы, оценка качества предсказаний и объяснений.
